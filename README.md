# TerraFly-Forensics: A Dataset for Forensic Detection of Generated Map Images with Quality Assessment of Generative Models

## Overview
TerraFly-Forensics is a dataset designed to facilitate research on forensic detection of generated map images. It includes real maps and synthesized map images generated using the advanced generative models. The study evaluates the effectiveness of existing forensic detection methods and provides quality assessments of generative models.

## Dataset
The dataset is hosted on Google Drive and can be accessed here:
[https://drive.google.com/drive/folders/1lgopTB5XGvTkQtzoC62lbGZSUVGGUFaF?usp=sharing]

**Note**: By downloading this dataset, you agree to the [Creative Commons Attribution-NonCommercial 4.0 International License](https://creativecommons.org/licenses/by-nc/4.0/).

The dataset consists of seven folders:
1. One folder contains real map images downloaded from the TerraFly mapping system.
2. The remaining six folders include synthesized map images generated by advanced generative models.

For detailed information on these generative methods and their performance in map generation, please refer to [`Generative_Models/README.md`](Generative_Models/README.md).
